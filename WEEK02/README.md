# Enterprise Infrastructure Planning for a Startup Company

## Project Overview
This project involves designing a complete initial IT Infrastructure Plan from scratch for ABC Startup Solutions, a newly established software development company. It covers hardware, software, networking inventories, and an architectural topology diagram to support the business operations of 20 employees across four departments.

## Learning Objectives
* Explain the roles and responsibilities of a System Administrator.
* Identify the hardware, software, and networking requirements of a small business.
* Describe the purpose of IT documentation and infrastructure planning.
* Analyze organizational IT requirements and prepare professional IT inventories.
* Design an enterprise network topology using Draw.io.
* Create technical documentation using Markdown.

## Company Scenario
* **Company:** ABC Startup Solutions
* **Nature of Business:** Software Development 
* **Current State:** 20 employees occupying a single office floor with zero existing IT infrastructure. 
* **Departments:** Information Technology (5), Human Resources (4), Finance (5), Sales (6). 
* **Objective:** Prepare a complete, scalable, and secure IT Infrastructure Plan before the purchasing phase begins.
